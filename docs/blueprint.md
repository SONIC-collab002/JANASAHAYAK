# **App Name**: JanSahayak

## Core Features:

- Issue Reporting: Citizens report issues via a form with photo upload, category selection, and GPS tagging. Includes tool to confirm location validity and suggest issue categories based on provided image using AI.
- Public Tracking: Timeline-based public view for each ticket (Submitted → Approved → In Progress → Resolved).
- Admin Dashboard: A dashboard for officials to manage, assign, and update issue statuses.

## Style Guidelines:

- Primary color: HSL 40, 90%, 50% which is close to a bright Yellow-Orange (#F0A202) to convey energy and optimism for civic engagement.
- Background color: A very light tint of the primary color, HSL 40, 20%, 95% (#FEF8F1) for a warm, inviting, accessible feel. This fits with a light color scheme, so elements such as the typography will need to be relatively dark.
- Accent color: HSL 10, 70%, 50% close to a bright Orange-Red (#E65C00), contrasting, is used for calls to action and important notifications.
- Font Pairing: 'Poppins' (sans-serif) for headlines and short text snippets to ensure readability. 'PT Sans' (sans-serif) is used for the body for comfortable reading.
- Use clear, universal icons. Ensure they are distinct and recognizable even at smaller sizes. Icons should match the chosen color palette and have a unified visual style.
- Clean, intuitive layout focused on usability across devices. Prioritize key information. Minimize clutter. Consistent information architecture for ease of navigation.
